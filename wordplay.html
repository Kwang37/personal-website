01 / Why it matters

An accessible language is more than translated buttons.

Wordplay is a web-based educational programming language and IDE for building interactive typography with youth and teachers at the University of Washington.

Learning to program is already a cognitively demanding task. If instructions, navigation and core terms only work comfortably in English, language becomes an additional barrier. Translating an educational interface means preserving meaning and making the interface readable, discoverable and usable.

02 / My contribution

English-to-Chinese, end to end.

My work covered translating interface copy and tutorial content from English into Chinese, maintaining Chinese locale files, checking how translations render in the actual interface, participating in review/pull-request workflows and testing screen-reader accessibility. My resume estimates over 20 pages of localized content.

Terminology & clarity

Translate programming instructions so learners can understand concepts rather than encounter awkward literal translations.

In-context verification

Check translated copy in real UI layouts, where label length and context can alter meaning.

Locale maintenance

Work within structured translation files and review process rather than editing hard-coded English UI strings.

Accessibility

Verify that translated UI supports screen-reader navigation and comprehension.

Wordplay’s IDE, compiler and global localization infrastructure are shared open-source achievements; this page describes my scope within that broader team.

05 / Reflection

Language inclusion requires testing after translation.

It is easy to mistake a translation file with a localized experience. What matters is whether a learner can actually navigate the product, understand instructions and access the same learning path. My takeaways include checking terminology in context, reviewing screen-reader behavior, and keeping translation decisions consistent across tutorial and UI surfaces.

What this adds to my product practice: Designing for accessibility and multiple languages means noticing assumptions other users may never share.
