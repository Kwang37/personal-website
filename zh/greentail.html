项目背景UW INFO 442 · 团队 MVP
时间2025 年秋
问题个人贡献用户流程隐私设计功能细节测试复盘

买到真正合适又可持续的宠物食品，不应那么困难。

宠物主人希望兼顾营养、预算与环境影响，却往往难以比较不同品牌的成分、认证和可持续性声明。

团队研究了两类目标用户：Emma 是重视原料透明度、环境影响和隐私的成熟养宠者；Sarah 是需要简明喂养教育和循序引导的新手。产品必须同时提供深入比较与低学习成本的发现路径。

Emma / 透明决策

不注册账号，也可以审阅配料、环境指标、价格和产品对比。

Sarah / 引导式学习

通过一套简短问题找到合适的产品，再用易懂的内容了解推荐理由。

把分散的功能串成一次连贯的购物决策。

我优化了从首页发现、五步问卷、推荐结果、商品比较到附近商店的完整流程。仓库里的页面架构文档指出了结果筛选不够醒目、对比信息不够充分、操作入口缺失等问题，因此设计重点是让用户能够继续采取行动，而不只是看到产品列表。

发现了解产品价值→问卷收集宠物和偏好→匹配得到推荐与解释→比较衡量营养、预算和环保→附近商店探索购买场景

先让用户体验价值，不必先交出个人信息。

我主张用客户端状态与浏览器 localStorage 支持基本偏好保存，并让创建账号成为可选流程，而不是进行商品搜索、问卷与比较的前置条件。

实际代码使用 React Context 保存问卷答案，核心探索流程不强制登录；收藏列表和演示级账号数据使用 localStorage。这有助于减少初步探索时对中心化用户档案的依赖，但 localStorage 并非加密储存，也不等于完整的数据安全方案。

降低首次使用门槛

让环保、营养和预算的权衡可见。

可理解的多因素匹配

团队的加权匹配算法考虑宠物类型、生命周期、体重、排除食材、预算、环保特征及喂养方式，并返回最多八个排名靠前的推荐。

不止展示“最佳推荐”

商品对比方案强调横向展示蛋白质、脂肪、纤维、主要配料、价格与适用场景，让用户能理解为何选择某款产品。

诚实呈现地图数据

React-Leaflet 地图根据 ZIP code 和产品品牌筛选模拟商店；商店库存和位置为 Demo 数据，不能宣传成实时准确的商家库存。

为新手提供教育内容

视频组件与配料标签、organic 定义、换粮指南等内容帮助用户完成决策，而不是让用户在专业信息前停滞。
