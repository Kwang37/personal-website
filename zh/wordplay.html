01 / 项目背景

编程教学不能只靠逐字翻译

Wordplay 是支持多语言和无障碍使用的网页版创意编程工具。对初学者来说，教程要讲得明白，按钮和提示也要容易理解。如果照着英文句式逐字翻译，不仅读起来生硬，还可能影响页面排版或操作指引。

02 / 工作内容

我负责的中文本地化工作

界面文案翻译

调整按钮、导航、提示和帮助说明的中文表达，让用户不用先理解英文句式就能操作。

教程与教学内容

翻译教程与教学说明，在不改变技术含义的前提下统一术语，让句子更符合中文阅读习惯。

维护中文语言文件

维护 zh-CN 语言文件，核对字段和格式，确保页面能正确读取译文。

显示检查与无障碍测试

检查译文在页面上的显示效果、屏幕阅读器朗读情况，并参与翻译审校和 GitHub PR 讨论。

03 / 语言文件

中文内容如何在项目中维护

项目将中文界面、教程、使用指南等内容分别保存在语言文件中。部分条目仍带有机器翻译或待审核标记，因此还需要持续校对，不能把文件里有中文就当作本地化已经完成。

06 / 项目收获

翻译完成后，还要检查是否好用

翻译完并不代表用户就能用好。还要检查按钮文字是否显示完整、术语是否前后一致、屏幕阅读器能否正确朗读，才能真正降低使用门槛。
