让软件“有中文”，和真正“适合中文学习者”，不是一回事。

Wordplay 是华盛顿大学团队与青少年、教师共同建设的网页版编程语言和 IDE，用于创作互动文字作品。

初学者本就需要理解陌生的编程概念；如果导航、教程和术语又只能以英文顺畅使用，就会引入额外的学习障碍。本地化不仅要翻译文字，也要保持概念一致、教学语气自然、交互结果可读。

Wordplay 项目简介 体验 Wordplay

我的核心贡献：从英文到中文的完整本地化工作。

我参与英文 UI 文案、教程和学习内容的中文翻译，维护中文语言文件，检查译文在界面中是否正确显示，并参与屏幕阅读器测试、翻译审核和 PR 协作。

UI 文字和术语

让导航、按钮、提示与技术术语在中文语境中易于理解、保持一致。

教程和学习材料

不仅校对逐词翻译，还调整自然度、可读性和教学说明的逻辑。

语言文件和审核

维护本地化资源结构、检查格式与渲染，以及协作审查修改。

无障碍测试

检查中文在实际 UI 和屏幕阅读器中的表现，避免“翻译完成但无法使用”。

这段经历提醒我，语言不是发布前最后加上的一层文案，而是产品体验本身的一部分。教程结构、术语一致性、读屏方式和不同语言的表达长度，都可能改变用户能否顺畅完成任务。

未来希望把译文审查与更系统的可访问性测试结合起来，记录本地化问题的类型、影响范围和解决方式，而不只计算完成了多少字符串。
